About AirIndx

AirIndx is an advanced Air Quality Index Prediction system. It uses machine learning models (Random Forest) to analyze real-time meteorological data and predict the AQI for any city worldwide.

Technology Stack

  • Frontend: HTML, Vanilla CSS (Glassmorphism), JavaScript
  • 3D Visualization: WebGL via Globe.gl & Three.js
  • Charts: Chart.js
  • Backend: Python, Flask
  • Machine Learning: Scikit-Learn (Random Forest Regressor)

Data Sources & Monitors

The system connects to global air quality networks:

  • Open-Meteo: Provides free global weather and air quality APIs.
  • WAQI: World Air Quality Index project providing real-time data (requires API token).
