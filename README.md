# 🌍 AI Agent for Air Quality Monitoring

An intelligent web-based air quality monitoring system that combines **Artificial Intelligence, Machine Learning, real-time air-quality data, geolocation, and an agentic workflow** to analyze air pollution and provide automated health precautions.

The system allows users to search for any city or locality, visualize its location on an interactive 3D Earth, retrieve air-quality information, predict AQI using a Machine Learning model, identify the dominant pollutant, assess environmental risk, and generate an automated agent decision.

---

## 📌 Project Overview

Air pollution is a major environmental and public-health concern. Conventional air-quality dashboards generally display pollution data but do not provide an intelligent workflow that interprets the data and takes a decision based on it.

This project introduces an **AI Agent for Air Quality Monitoring** that performs a complete analysis pipeline:

```text
User Location
      ↓
Location Identification
      ↓
Latitude & Longitude
      ↓
3D Earth Visualization
      ↓
Air Quality Data Retrieval
      ↓
Pollutant Analysis
      ↓
Machine Learning AQI Prediction
      ↓
AQI Category
      ↓
Dominant Pollutant Detection
      ↓
Environmental Risk Assessment
      ↓
Agent Decision
      ↓
Automated Health Precaution
